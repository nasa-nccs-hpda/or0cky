# ROCKE-3D JAX port (minimal branch)

JAX port of the ROCKE-3D atmosphere model (ModelE), with the code, tests and recipes needed to run and score the release and fast configurations against recorded Fortran runs.

Start in `rocke3d_jax/`:

* `rocke3d_jax/README.md`: what is where.
* `rocke3d_jax/STATUS_20261016.md`: what was verified, and the open replication gaps. Read it before citing any result.
* `rocke3d_jax/DATA_AND_PATHS.md`: the data, binaries and environments that live outside this repository, and how to run everything with `rocke3d_jax/gpu/run_variants.sh`.

This is a minimal branch. The full development history, scoping notes, drafts and run records are in the earlier branches and tags of this repository; the archive point is the tag `archive/full-fidelity-port-20261016`. The previous `main` (2026-09-28) is unchanged.
