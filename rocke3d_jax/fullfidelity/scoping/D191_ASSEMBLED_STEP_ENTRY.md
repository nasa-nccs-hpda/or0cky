## 4. ACCEPTANCE section 1, item by item (measured, nov26 steady; dec01/jan01 within the ranges shown)

## 7. Limits and open items
- Step 0 of three dates and a six-step chain on one date; replayed radiation (server on nov26 step 0 only); cores 0-2,6-7 only; one run per timing; node shared.
- Recorded: Ent exports, land forcing, tile radiation columns (SRHEAT/TRHR0), TRUP_in_rad, irrigation demand, PBL profile columns of the template, RADIA surface side (server run), the CONDSE entry set `ci`.

- Host callbacks inside jit deadlock on one core (>= 2 cores needed; five used here).
- Tests (own unit only): `tests/test_jax_phase2.py` 4 passed (10 s), `tests/test_jax_coupled.py` 2 passed (26 s), cores 0-2,6-7. The full suite and other files were not run.
