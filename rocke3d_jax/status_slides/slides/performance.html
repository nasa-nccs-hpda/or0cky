Reading this honestly

JAX-CPU is not a blanket win — it loses DRYCNV outright to Fortran on CPU (small-array dispatch overhead dominates at this grid size).

GPU wins decisively on isolated kernels (2.3–6.3×) — but not on the full chained pipeline (~1.0×). The grid is too small either way for GPU to be a clean win by itself.
